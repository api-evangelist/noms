# Noms

> Noms is a REST API for nutrition data: foods, brands, nutrients and food groups, with barcode lookup and nutrient values per 100 g or 100 ml.

## Using the API

- Base URL: `https://api.noms.sh`. Every endpoint is under `/v1`.
- Send an API key in the `X-API-Key` header on every request. `Authorization: Bearer <key>` also works.
- A list returns `{data, links, meta}`. Follow `links.next` for the next page. A single item returns `{data}`.
- Errors are RFC 9457 problem details. Each one carries a `doc_url` that links to its entry in the reference.
